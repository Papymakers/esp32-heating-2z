# Hardware — Carte principale

Carte principale ESP32-C6 — contrôleur 2 zones fil pilote, lecture Linky TIC,
EEPROM I2C, switches physiques, LED RGB et afficheur TM1637 (4 digits).

---

## Fichiers fournis

| Fichier | Description |
|---------|-------------|
| `main-board/schematic_main_board.png` | Schéma électronique de la carte |
| `main-board/Heating-Control_main-board.jpeg` | Vue de la carte assemblée |

Le schéma est fourni à titre de référence, pour comprendre le montage, le reproduire
ou l'adapter. Les fichiers de fabrication (Gerbers, BOM, sources EasyEDA) ne sont pas
publiés dans ce dépôt.
